# Birthday Website
A simple birthday website built as part of the Scrimba Fullstack Developer Career Path. This project helped me better understand more on the capacity of using Flexbox as for other CSS features. The layout has different presents for a section. For when you hover it with your mouse, it reveals a gif corresponding to the message. Completed on 8/11/26.

## Skills

- Flexbox align-items
- flex-direction
- :hover effect
- CSS gradients
- grouping selectors

## Technologies Used

- Visual Studio Code
- HTML5
- CSS3
