# Counter App

A simple interactive counter. With clicking the buttons, they increment the count and/or save the previous count. In the bottom it displays previous saves.

## Skills

- script tags
- variables
- datatypes
- functions
- DOM

## Technologies Used

- Visual Studio Code
- HTML5
- CSS3
- JavaScript
